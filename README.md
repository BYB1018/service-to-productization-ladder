# Service-to-Productization Ladder

## 中文

把已经有人付费的人工或半自动服务，按真实交付记录逐步沉淀为模板、Skill、虚拟产品或 Agent。

适用于“服务如何产品化”“是否该做 SaaS”；不用于尚未验证需求的点子。每一步都应由重复交付证据支持，不默认所有服务都要变成软件。

## English

Use real delivery records to turn an already-paid manual or semi-automated service into templates, Skills, digital products, or an Agent step by step.

Use it to decide how to productize a service or whether SaaS is warranted. Do not use it to productize an unvalidated idea. Each step should be supported by repeated delivery evidence; not every service needs to become software.
